# Refonte front-end – ASFC (SAE S3)

Copie statique (pages en .html) du site de l'Association Française du Syndrome de Fatigue Chronique (https://www.asso-sfc.org), reprise dans un cadre scolaire pour refaire le front-end (layout responsive, labels de formulaires, contrastes, liens explicites).

- `css/style.css` : feuille de style d'origine (à découper en plusieurs fichiers)
- `*.html` : pages du site (renommées depuis `.php`)
- `documents/` (PDF) non versionné
